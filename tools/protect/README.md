# 頁面加密碼（StatiCrypt）

給旅遊文件這類「只想給特定的人看」的頁面用。頁面內容先加密再放上來，打開時輸入密碼，在瀏覽器裡解開。

## 原則

- **明文不能 commit 進這個 repo**（它是公開的）。工作檔放 `_private/`（已加入 `.gitignore`），或放在 repo 外面。
- **密碼不寫進任何檔案**。每趟旅程用一組，至少 16 個字，例如四個不相關的詞。加密後的檔案誰都下載得到，可以離線一直猜，所以密碼要長。
- **網址和首頁上的標題沒有加密**：不要寫確切日期、地點細節或人名。密碼頁的標題固定是「需要密碼」。
- **只有網頁和裡面的圖片會加密**。PDF 等其他檔案沒辦法加密，工具會擋下來，請先轉成網頁或圖片。

## 需要

- Node.js：`npx` 會自動下載固定版本的 `staticrypt@3.5.4`
- Python 3：`pip install pillow pillow-heif`（`pillow-heif` 用來讀 iPhone 的 HEIC 照片）

## 用法

在 repo 根目錄執行：

```sh
STATICRYPT_PASSWORD='密碼' python3 tools/protect/protect.py _private/旅程.html travel/旅程代號/ --share
```

- 來源裡 `<img>` 用到的本機圖片：轉正、長邊縮到 1280px、清掉 EXIF（含 GPS 和手機型號），內嵌後跟文字一起加密。
- 輸出到 `travel/旅程代號/index.html`。密碼頁是中文、有 noindex、支援深色模式。
- 寫出檔案前會檢查：加密後的檔案裡找不到原文和圖片，才算成功。
- `--share`：印出免輸入密碼的分享連結。連結裡是密碼的雜湊，被轉傳就等於密碼外流。
- 「記住這台裝置」預設 30 天，用 `--remember 天數` 改（`0` 不過期，`-1` 不提供這個選項）。
- `--hint '文字'`：換掉密碼頁上的說明文字（一樣不要寫人名、地點、日期）。

更新內容時，用同一組密碼重跑一次就好；已經記住的裝置和分享連結都還能用。

## 不要改的檔案

- `staticrypt.json`：固定的 salt（公開沒關係）。改了以後，已經記住的裝置和分享連結都會失效。
- `template.html`：密碼頁的樣板，改自 StatiCrypt 的預設樣板，授權見 `LICENSE-staticrypt.txt`。
